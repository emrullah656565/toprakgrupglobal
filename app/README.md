# Toprak One

Toprak Grup Global için React Native + Expo ile geliştirilen mobil uygulama.

## İlk sürüm
- Premium siyah/altın mobil arayüz
- Ana sayfa
- Akıllı mağaza ve ürün arama
- Toprak AI paneli
- Kamerayla lastik ölçüsü okuma alanı (UI hazır, kamera bağlantısı sonraki aşama)
- Benim Garajım
- Hesabım
- Fiyat alarmı ve karşılaştırma girişleri

## Çalıştırma
```bash
cd app
npm install
npx expo start
```

Expo Go ile QR kodu tarayarak Android/iPhone üzerinde test edilebilir.
